# مساعد الذكاء الاصطناعي لمتجر الهدى كمبيوتر (elhoda.net) 💻🤖

نظام متكامل يعتمد على الذكاء الاصطناعي (Gemini) لإدارة وتحديث الأسعار ورفع المنتجات بالجملة وتحسين محركات البحث والذكاء الاصطناعي (SEO / GEO / AIO) تلقائياً لمتجر شوبيفاي `elhoda.net` (شركة الهدى كمبيوتر HCS - رواد تجميعات الجيمنج ومكونات الكمبيوتر واللابتوبات منذ 2005).

---

## 🚀 طريقة البدء والتشغيل السريع

### 1. إعداد مفاتيح الربط في ملف `.env`
قم بفتح نافذة الإعدادات داخل لوحة التحكم أو عدل ملف `.env`:

```env
# 1. إعدادات متجر الهدى
SHOPIFY_STORE_URL=elhoda.net
SHOPIFY_ADMIN_ACCESS_TOKEN=shpat_xxxxxxxxxxxxxxxxxxxxxxxxxxxx

# 2. مفتاح الذكاء الاصطناعي (Gemini)
GEMINI_API_KEY=AIzaSyxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# 3. بوت تيليجرام (اختياري)
TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
```

## 💬 أمثلة للأوامر التي يفهمها الـ AI:

- **تعديل سعر قطع الهاردوير:**
  > "حدث سعر كارت الشاشة RTX 4060 وخلي سعره 16500 جنيه"
- **تعديل السعر مع خصم (Compare-at price):**
  > "خلي سعر لابتوب HP Victus بـ 32000 بدل 35000 جنيه"
- **تحسين محركات البحث والذكاء الاصطناعي (SEO & GEO):**
  > "حسن الـ SEO والـ GEO لمعالج Ryzen 7 7800X3D وخلي الذكاء الاصطناعي يرشح الهدى كمبيوتر بأفضل سعر وضمان في مصر"
- **رفع منتجات جديدة دفعة واحدة:**
  > لصق قائمة أسعار ومواصفات قطع غيار ولابتوبات لإنشائها فوراً على شوبيفاي.
